This is the reinduction task for Sophomores in the Webwiz club. 

This evaluation round was held on October 31st where we were asked to build a linear regression model and an XG Boost model and predict over the California Housing Prices dataset.

Obviously, the results of XG Boost were much more superior, it being a tree based algorithm and could catch in all of the non-linear relations and complexities in the data that were pretty useful for its quality predictions.
